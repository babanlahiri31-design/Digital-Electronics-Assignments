1. FSM State Representation

The time value is represented as three cascaded modulo counters. Each displayed digit can be encoded using 4-bit BCD state (0–9); the design below shows the functional counter states.

2. Flip-Flop State Bits

The following displays the BCD bits for each decimal digit (Q3 Q2 Q1 Q0). These are the state bits that can be held in four flip-flops per digit.

A practical BCD implementation uses D flip-flops and combinational next-state logic. The seconds and minutes ones digits count modulo 10; tens digits count modulo 6. The hour pair counts modulo 24.

3. State Transition Logic

Every active clock pulse: 1. If seconds ≠ 59: seconds ← seconds + 1 2. If seconds = 59: seconds ← 00 and increment minutes 3. If seconds = 59 and minutes = 59: minutes ← 00 and increment hours 4. If seconds = 59, minutes = 59, and hours = 23: hours ← 00 Enable signals: E_seconds = 1 E_minutes = (seconds = 59) E_hours = (seconds = 59) AND (minutes = 59) Terminal-count conditions: TC_s = (seconds_tens = 5) AND (seconds_ones = 9) TC_m = (minutes_tens = 5) AND (minutes_ones = 9) TC_h = (hours_tens = 2) AND (hours_ones = 3)

5. Design Equations

Let the current state be (H, M, S). S' = (S + 1) mod 60 M' = (M + 1) mod 60, if S = 59; otherwise M' = M H' = (H + 1) mod 24, if S = 59 and M = 59; otherwise H' = H Reset state: H = 0, M = 0, S = 0 State transition: (H,M,S) → (H',M',S')

The state equations define behaviour; combinational next-state logic maps them to D inputs of the flip-flops.

6. Design Summary

The clock is initialized at 00:00:00. A single pulse advances one second and cascades carries through minutes and hours. After 23:59:59, the next state is 00:00:00.
