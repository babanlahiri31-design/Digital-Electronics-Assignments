AI Digital Circuit Verifier

Specify the intended logic, then verify a circuit screenshot or a truth table against it.

1. Desired circuit behaviour

Examples: A'B + AB' (XOR); AB + AC + BC. Use variable names A–D. Parentheses are supported.
This defines the target function. The verifier generates its expected output for every input combination.

2. Choose what you want to verify

The tool will generate every input combination. Enter the output(s) from your circuit, then compare them with the target function.
Screenshot mode needs a vision-capable AI service to automatically read gates and wires. This offline demo can preview the screenshot, but cannot reliably reconstruct a circuit from pixels by itself.
The manual fallback lets the local tool compare an expression you transcribe. It is not automatic screenshot recognition.

3. Target logic reference

Select a target circuit and build the table.

Logic structure preview

Expected Boolean equations will appear here.

4. Verification report

Build the table, enter observed output values, and verify.
Mismatch diagnosis will appear here.

5. Truth table

Expected outputs are calculated from the target. Enter your circuit's observed output(s) in the “Actual” columns.

6. What the result means

A PASS means the entered outputs match the target for all combinations. A mismatch points to one or more combinations that need circuit inspection.
