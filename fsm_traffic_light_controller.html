4. D flip-flop logic equations

State encoding: GREEN=00, YELLOW=01, RED=10, WALK=11. R = pedestrian request input; P = stored pending request. D₁ and D₀ feed the two state D flip-flops.

D₁ = (¬Q₁ · Q₀) + (Q₁ · ¬Q₀ · (P + R))
D₀ = ¬Q₀ · (¬Q₁ + P + R)
P⁺ = (P + R) · ¬(Q₁ · ¬Q₀ · (P + R)) · ¬(Q₁ · Q₀)

Here + means OR, · means AND, and ¬ means NOT. The request flip-flop stores a request until the RED phase sends the FSM to WALK, then clears it.
